# PROJECT: DUNGEON

브라우저에서 바로 실행되는 탑다운 로그라이크 슈터입니다. 외부 라이브러리나 이미지 파일 없이 HTML 파일 하나로 동작합니다.

## 실행 방법

`index.html`을 브라우저(Chrome, Edge, Firefox 등)로 열면 바로 플레이할 수 있습니다. 키보드와 마우스가 필요합니다.

## 조작법

| 키 | 동작 |
|---|---|
| WASD | 이동 |
| 마우스 | 조준 / 클릭으로 공격 (차지 무기는 누르고 있다가 놓기) |
| Space | 대시 (짧은 무적) |
| F / 우클릭 | 캐릭터 스킬 |
| E | 상호작용 (상자, 무기 줍기, 상점, 로비 오브젝트) |
| Q / 마우스 휠 | 무기 교체 |
| Esc | 일시정지 / 조작법 |

## 게임 구성

- **로비**: 캐릭터 선택·해금, 무기 도감, 무기고(시작 보조 무기 해금·장착), 훈련용 허수아비(DPS 측정), 던전 입장 포탈
- **캐릭터 4명**: 검사(회오리 베기), 사수(과부하 사격), 마도사(서리 폭발), 기술자(자동 포탑)
- **던전**: 이끼 숲 → 서리 동굴 → 용암 요새, 월드마다 x-1·x-2 일반 스테이지와 x-3 보스 스테이지
  - 절차적으로 생성되는 방 구조, 전투방(문 잠금 + 웨이브), 보물방, 상점, 출구 포탈
  - 보스 3종: 젤리 폭군, 서리 거상, 화염 군주 / 보스 처치 시 버프 선택
- **무기 56종**: 사격 31 · 지팡이 7 · 근접 11 · 활·특수 7 (일반 / 고급 / 희귀 / 영웅)
  - 관통, 폭발, 유도, 벽 반사, 연쇄 번개, 부메랑, 지뢰, 집속탄, 흡인, 차지, 광선, 상태이상(화상·빙결·중독) 등
- **진행도 저장**: 로비 골드, 해금 캐릭터, 발견한 무기, 무기고는 브라우저 localStorage에 저장됩니다

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 최신 버전 (Phase 4: 오리지널 픽셀아트, 고해상도 렌더링, 무기고, 밸런스 패치) |
| `versions/phase1.html` | Phase 1: 기본 전투 프로토타입 (방 1개, 슬라임) |
| `versions/phase2.html` | Phase 2: 절차적 던전, 카메라·미니맵, 무기 6종, 적 4종, 보스 |
| `versions/phase3.html` | Phase 3: 로비, 캐릭터 4명, 3개 월드, 상점, 버프, 무기 19종 |

## 구조

데이터(캐릭터·무기·적·월드·버프)는 파일 상단의 `DATA_*` 배열에 모여 있어서, 새 무기나 적은 대부분 데이터 항목만 추가하면 됩니다. 스프라이트는 코드 안의 문자 격자(`PIX`, `WPIX`)로 그려져 있습니다.
