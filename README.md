# PROJECT: DUNGEON

브라우저에서 바로 실행되는 탑다운 로그라이크 슈터입니다. 외부 라이브러리나 이미지·사운드 파일 없이 동작합니다. 그래픽은 코드 안에 그린 픽셀아트이고, 효과음은 WebAudio로 즉석에서 합성합니다.

## 실행 방법

`index.html`을 브라우저(Chrome, Edge, Firefox 등)로 열면 바로 플레이할 수 있습니다. 파일을 더블클릭해서 열어도 되고, GitHub Pages로 배포해도 됩니다. 키보드와 마우스가 필요합니다.

## 계정

첫 화면에서 닉네임과 4자리 PIN(선택)으로 계정을 만들 수 있습니다. 계정마다 로비 골드, 해금 캐릭터, 도감, 무기고가 따로 저장되고, 로그인 없이 게스트로 바로 할 수도 있습니다(게스트는 저장되지 않음). 로비에서 Esc → L로 로그아웃합니다.

계정은 **이 브라우저의 localStorage에만** 저장됩니다. 서버가 없는 정적 사이트라서 다른 기기와 공유되지 않고, PIN은 해시로만 저장하지만 보안 장치는 아닙니다. 주소 끝에 `?guest=1`을 붙이면 로그인 화면 없이 게스트로 시작합니다(테스트 도구용).

## 조작법

| 키 | 동작 |
|---|---|
| WASD | 이동 |
| 마우스 | 조준 / 클릭으로 공격 (차지 무기는 누르고 있다가 놓기) |
| Space | 대시 (짧은 무적) |
| F / 우클릭 | 캐릭터 스킬 |
| E | 상호작용 (상자, 무기 줍기, 상점, 로비 오브젝트) |
| Q / 마우스 휠 | 무기 교체 |
| M | 소리 켜기/끄기 |
| Esc | 일시정지 / 조작법 |

## 게임 구성

- **로비**: 캐릭터 선택·해금, 무기 도감, 무기고(시작 보조 무기 해금·장착), 훈련용 허수아비(DPS 측정), 던전 입장 포탈
- **캐릭터 4명**: 검사(회오리 베기 + 패시브 단련된 갑옷), 사수(과부하 사격), 마도사(서리 폭발), 기술자(자동 포탑)
- **던전 16층**: 이끼 숲 → 서리 동굴 → 용암 요새 → 공허 성채. 월드마다 x-1~x-3 일반 스테이지와 x-4 보스 스테이지가 있습니다. 2월드부터 정예 몬스터가 섞여 나옵니다.
  - 절차적으로 생성되는 방 구조, 전투방(문 잠금 + 웨이브), 보물방, 상점, 출구 포탈
  - 보스 4종: 젤리 폭군, 서리 거상, 화염 군주, 심연의 눈
  - 보스전: 등장 연출(낙하·타이틀 카드), 3페이즈(66%·33%에서 패턴 추가), 3페이즈 궁극기, 처치 슬로우모션, 보스전 배경음악. 페이즈가 바뀔 때마다 에너지와 회복 물약이 떨어지고, 보스를 잡으면 체력 50% 회복과 버프 선택이 주어집니다.
- **무기 70종**: 사격·지팡이·활 48 · 근접 13 · 차지 7 · 광선 2 (일반 / 고급 / 희귀 / 영웅)
  - 관통, 폭발, 유도, 벽 반사, 연쇄 번개, 부메랑, 지뢰, 집속탄, 흡인, 차지, 광선, 상태이상(화상·빙결·중독)
  - 거품탄, 투창, 화염 웅덩이, 시한 수류탄, 적 사이를 튕기는 원반, 원형 탄막, 공중에서 터지는 폭죽, 전투 드론 소환, 궤도 구슬, 검기, 탄 반사 방패, 일직선 충전 광선
- **원소 반응**: 빙결+화상 = 열충격(큰 피해), 중독+화상 = 독 연소(주변 폭발), 빙결+번개 = 감전(연쇄 피해 1.5배)
- **진행도 저장**: 로비 골드, 해금 캐릭터, 발견한 무기, 무기고, 소리 설정은 브라우저 localStorage에 저장됩니다.

## 코드 구조

빌드 과정 없이 일반 `<script>` 파일들을 `index.html`에서 순서대로 불러옵니다. 파일을 직접 열어도 동작하게 하려고 ES 모듈 대신 이 방식을 씁니다. 모든 파일은 같은 전역 범위를 공유하므로 **불러오는 순서가 중요합니다.**

```
js/
  data/        게임 데이터 (밸런스 패치는 대부분 여기만 수정)
    heroes.js    캐릭터 능력치·스킬·패시브
    weapons.js   무기 70종
    enemies.js   적·보스 (보스 패턴과 격노 패턴 포함)
    worlds.js    월드 구성, 버프
    balance.js   난이도 곡선, 경제, 드롭률, 가격
    index.js     id → 정의 조회용 GAME_DATA
  core/        공용 기반
    util.js      상수, 수학/랜덤 유틸
    save.js      localStorage 저장 (계정별 칸)
    auth.js      기기 안의 계정(닉네임 + PIN 해시)
    sound.js     WebAudio 효과음 (SFX.play('이름'))
    input.js     키보드·마우스 입력
    loop.js      고정 timestep(60Hz) 게임 루프
    collision.js 타일 충돌, 레이캐스트, 피해 계산
  art/pixel.js 픽셀아트 스프라이트(PIX, WPIX), 타일 텍스처, 그리기 함수
  world/map.js 던전 맵, 절차적 생성, 로비 맵
  entities/    플레이어·적(actors), 투사체·장판·포탑(projectiles), 픽업·상자·상점·로비 오브젝트(props)
  systems/     무기 발사(weapons), 몬스터 AI·보스 패턴(ai), 이펙트(effects)
  ui/hud.js    HUD, 미니맵, 도감·무기고·버프·결과 화면
  ui/login.js  로그인 화면 (HTML 오버레이)
  game.js      게임 상태, 방 진행, 전투 처리, 렌더링
  main.js      시작점
```

### 자주 하는 작업

- **무기 추가**: `js/data/weapons.js`에 항목을 추가합니다. 그림은 `js/art/weapons.js`에 픽셀 그림을 추가하고 `WEAPON_SPRITE`에 연결합니다.
- **적 추가**: `js/data/enemies.js`에 항목을 추가하고, `aiType`으로 기존 행동(melee_chase, ranged_kite, charger, caster, exploder, teleporter, turret)을 고른 뒤 `js/data/worlds.js`의 출현 목록에 넣습니다.
- **보스 패턴 추가**: `js/systems/ai.js`의 `BOSS_PATTERNS`에 `update()`를 구현하고, 보스 데이터의 `patterns`(1페이즈) / `phase2Patterns`(66%~) / `finalPatterns`(33%~, 궁극기)에 넣습니다. 패턴에 `name`을 주면 사용할 때 이름을 외칩니다.
- **월드 추가**: `js/data/worlds.js`에 월드(팔레트, 적 목록, 보스)를 추가하면 스테이지 수가 자동으로 늘어납니다.
- **난이도·경제 조정**: `js/data/balance.js`

## 개발 도구 (`tools/`)

Node.js와 Playwright(Chromium)가 필요합니다. 모든 도구는 화면 없이 게임을 실제로 실행합니다.

| 명령 | 내용 |
|---|---|
| `node tools/smoke.js` | 무적 상태로 로비 → 3-3 승리 → 로비 귀환까지 전체 진행 확인 |
| `node tools/fuzz.js [분]` | 무작위 입력 퍼징 + 매 프레임 불변식 검사 (벽 끼임, NaN, 수치 범위, 누수, 잠긴 방) |
| `node tools/synergy.js` | 무기 × 공격력/공속 버프 × 과부하 사격 시너지 검증 |
| `node tools/boss.js [횟수]` | 보스별 승률, 처치 시간, 패턴별 받은 피해 |
| `node tools/sim.js real <heroId> <횟수>` | 실전형 봇(파밍·상점 이용)으로 클리어율·사망 위치 측정 |
| `node tools/sim.js weapon <weaponId> <횟수>` | 무기 하나만 들고 앞쪽 2개 월드 진행 |
| `node tools/power.js` | 무기별 화력(단일·범위 DPS)과 등급별 평균 |
| `node tools/login.js` | 계정 생성·PIN·로그아웃·삭제·계정 분리·기존 진행도 이전 검증 |

`tools/bot.js`는 측정 도구들이 페이지에 주입해서 쓰는 전투 봇입니다.
