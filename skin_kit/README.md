# 스킨 제작 키트

PROJECT: DUNGEON 스킨을 직접 그릴 때 쓰는 템플릿과 규칙이에요.
그림을 채팅에 올려 주면 배경 제거·크기 맞춤·게임 등록은 Claude가 합니다.

## 파일

| 파일 | 내용 |
|---|---|
| `01_common_template.png` / `01_common_example.png` | 일반 스킨 (앞모습 1장) |
| `02_legendary_template.png` / `02_legendary_example.png` | 전설 스킨 (3방향 × 걷기 3장 + 정지) |
| `03_transform_normal_template.png` / `..._example.png` | 변신 스킨 ① 평소 모습 |
| `03_transform_beast_template.png` / `..._example.png` | 변신 스킨 ② 변신 모습 |

템플릿은 게임 1픽셀을 4×4로 키워 둔 그림이에요. 격자 한 칸 = 게임 픽셀 하나.

- 빨간 띠: 발이 닿는 줄 (맨 아래). 모든 프레임에서 발끝을 여기에 맞추기
- 파란 점선: 몸 가운데. 몸통 중심을 여기에
- 노란 표시: 무기를 쥘 손 높이. 무기는 게임이 그려 주니 그리지 않기 (변신 스킨의 무기는 예외)

## 종류별 규격

| 종류 | 게임 크기 | 필요한 그림 | 움직임 |
|---|---|---|---|
| 일반 | 높이 22px, 폭 26px 이하 | 앞모습 1장 | 좌우 반전 + 걸을 때 1px 들썩 |
| 전설 | 22 × 27px | 앞·뒤·옆 × 걷기1·중간·걷기2 (9장), 정지 3장은 선택 | 이동 방향으로 바라봄, 걷기 초당 9장 |
| 변신 ① 평소 | 높이 27px 안팎 | 앞·뒤·옆 × 서기·걷기1·걷기2 (9장) | 걷기1 → 서기 → 걷기2 → 서기 |
| 변신 ② 변신 | 높이 40~48px, 폭 76px 이하 | 옆 대기, 옆 공격, 정면, 후면 | 정면·후면 공격 동작은 Claude가 만듦 |

## 꼭 지킬 것

1. **배경은 투명 또는 순수한 검정(#000000)**. 가이드 레이어는 끄고 보내기
2. **배경에 닿는 외곽선은 아주 까만색을 피하기**. RGB 합이 30 이하인 색은 배경으로 지워짐 → `#1a1426` 같은 짙은 남색 추천
3. **옆모습 방향**: 전설·변신① 은 왼쪽을 보게, 변신② (샘 같은 변신체)는 오른쪽을 보게
4. **걷기 프레임끼리 머리·몸통 위치 고정**, 다리만 움직이기 (안 그러면 걸을 때 떨림)
5. **발끝은 항상 맨 아랫줄**, 프레임마다 크기(머리 크기) 똑같이
6. **넓게 퍼지는 빛(글로우)·흐림 효과 자제**. 작게 줄이면 지저분한 테두리가 됨
7. 22~27px은 아주 작음 → 색 대비를 크게, 디테일은 굵게. 그린 뒤 25%로 줄여 보기

## 크기

- 템플릿 그대로(×4) 그리기를 가장 추천. 1:1 실제 크기로 그려도 됨
- 더 큰 일러스트(예: 400px)도 받아서 줄여 드리지만, 가는 선과 작은 장식은 사라짐

## 보낼 때 알려 줄 것

- 스킨 이름, 대상 직업 (전직 루트가 있으면 그것도)
- 등급: 일반 / 전설 / 변신 · 얻는 방법: 뽑기 / 선물 코드 / 상점
- 한 줄 설명 (스킨 창에 표시)
- 전설 뽑기 스킨이면 배너 그림(선택): 16:9, 1024×576 이상. 뽑기 화면에서 양옆이 잘려 가운데 약 80%만 보이니 인물·글자는 가운데에

## Claude가 하는 일

배경 제거 → 게임 크기로 줄이기 → 프레임 정렬(머리 중심·발끝) → 스프라이트 시트에 추가 → 좌표 등록 → 스킨 창·뽑기 배너 등록 → 게임에서 4방향 확인 스크린샷
